# graf-appBanderaMx
Práctica integradora - Aplicación Bandera de México
#Prompt 1:
Crea una aplicación web moderna y sencilla utilizando únicamente HTML, CSS y JavaScript, colocando cada uno en un archivo separado:

index.html
style.css
script.js
La interfaz debe permitir manipular y visualizar dos colores diferentes.

Requisitos de la interfaz:
Mostrar dos secciones, una para el Color 1 y otra para el Color 2.
Cada color debe tener:
Un selector de color (input type="color").
Controles RGB independientes para modificar los valores de Rojo, Verde y Azul.
Mostrar el código hexadecimal correspondiente al color.
Mostrar visualmente el color seleccionado dentro de un recuadro.
Los valores RGB deben actualizarse en tiempo real cuando el usuario mueva los controles.
El código hexadecimal también debe actualizarse automáticamente.
Agregar una sección donde se puedan visualizar los dos colores al mismo tiempo, para poder compararlos.
Agregar una funcionalidad para intercambiar los dos colores mediante un botón.
Agregar un botón para restablecer los colores a sus valores iniciales.
La página debe ser responsive y funcionar correctamente en computadora y celular.
Utiliza un diseño limpio, moderno y fácil de entender.
Puedes utilizar Bootstrap mediante CDN para mejorar el diseño, pero el HTML, CSS y JS deben seguir estando en archivos separados.
No mezcles CSS ni JavaScript dentro del archivo HTML.
El código debe estar completamente funcional y listo para copiar y pegar.
Incluye comentarios dentro del código para explicar las partes importantes.
Entrega el resultado separado claramente en:

index.html
style.css
script.js
Asegúrate de que los tres archivos estén correctamente conectados y que todas las funciones de manipulación de los dos colores funcionen sin errores.

Quiero que sea como una bandera de México.

#Prompt 3:
Crea una aplicación web moderna utilizando HTML, CSS y JavaScript, colocando cada uno en un archivo separado:

index.html
style.css
script.js
La interfaz debe estar inspirada visualmente en la bandera de México, utilizando sus tres colores principales: verde, blanco y rojo.

Requisitos:
Crear una bandera horizontal dividida en tres franjas verticales:
Verde a la izquierda.
Blanco en el centro.
Rojo a la derecha.
El usuario debe poder manipular los colores:
Un panel para modificar el color verde.
Un panel para modificar el color rojo.
Cada panel debe tener un selector de color y controles RGB.
Mostrar el código hexadecimal de cada color.
La bandera debe actualizarse en tiempo real cuando el usuario cambie los valores RGB.
La franja central debe permanecer blanca.
Agregar una representación sencilla de un escudo en el centro de la franja blanca utilizando HTML/CSS, sin necesidad de imágenes externas.
Mostrar debajo de la bandera los valores actuales:
Color verde: RGB y HEX.
Color rojo: RGB y HEX.
Agregar un botón para:
Intercambiar los colores verde y rojo.
Restablecer los colores originales de la bandera.
Utilizar Bootstrap mediante CDN para mejorar el diseño, pero mantener HTML, CSS y JavaScript en archivos separados.
No colocar CSS ni JavaScript directamente dentro del HTML.
La interfaz debe ser responsive y verse correctamente en computadora y celular.
Utilizar un diseño limpio, moderno y relacionado visualmente con México.
Los colores iniciales deben ser:
Verde: #006847
Blanco: #FFFFFF
Rojo: #CE1126
El código debe estar completamente funcional, comentado y listo para copiar y pegar.
Entrega los tres archivos completos y separados:

index.html
style.css
script.js
Asegúrate de que los tres archivos estén correctamente conectados y que al modificar los controles RGB la bandera cambie inmediatamente
